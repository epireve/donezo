# Donezo - AI-Powered To-Do List (Tasks Agent)

This is a Next.js to-do application with integrated AI features to help you manage your tasks more effectively.

## Features

*   Standard to-do functionalities: Add, list, complete, delete tasks.
*   Persistent storage using `localStorage`.
*   Light/Dark mode toggle.
*   **AI-Powered Enhancements:**
    *   Automatic Task Categorization/Tagging.
    *   Task Detail Enrichment (finding related info, links).
    *   Sub-task Generation.
*   **Personalization & Settings:**
    *   User profile for personalized AI assistance (background, interests, goals).
    *   Configuration for API providers (Gemini, OpenRouter) and models.
    *   Bring Your Own Key (BYOK) for AI services.

## Tech Stack

*   Next.js
*   React
*   TypeScript
*   Tailwind CSS

## Getting Started

1.  Clone the repository.
2.  Install dependencies: `npm install`
3.  Run the development server: `npm run dev`
4.  Open the application in your browser and configure your API key in the settings to use AI features.
